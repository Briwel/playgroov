# PocketGroove Studio

A mobile music studio combining classical signal processing tools with AI for automated workflows.

## Architecture

- **Apps:**
  - `mobile-app`: React-based mobile application.
  - `backend`: NestJS orchestrator.
- **Services:**
  - `demucs-service`: AI stem splitting (HTDemucs).
  - `basic-pitch-service`: Audio-to-MIDI transcription (Basic Pitch).
